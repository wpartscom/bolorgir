Bolorgir 0.1.0 is the first public release of an embeddable structured-generation engine for LLMs: a small Zig core with a versioned C ABI, Python bindings and a Hugging Face Transformers adapter. Given a JSON Schema or a set of literal strings, it computes the allowed next tokens at every generation step.

## Install

The package is not on PyPI. Build it from source; you need Zig 0.15.2, a C compiler and Python 3.10 or newer. Build the `main` branch: it carries the fixes made after this release ([CHANGELOG.md](https://github.com/wpartscom/bolorgir/blob/main/CHANGELOG.md), sections Unreleased and 0.2.0), among them a parser defect of 0.1.0 under which spec-v1 accepted the invalid document `8""` for `{"anyOf":[{},{},{}]}`.

```sh
git clone https://github.com/wpartscom/bolorgir
cd bolorgir
zig build -Drelease=true
python3 -m venv .venv && . .venv/bin/activate
python -m pip install --upgrade pip
cd python && pip install ".[transformers]"   # or: pip install . (no Transformers adapter)
```

`git clone --branch v0.1.0` builds this release exactly. The wheel and the sdist attached here are the 0.1.0 code, without those fixes.

## Platforms

- Linux x86_64 with glibc.
- CPython 3.10 to 3.13, through a single abi3 extension.

macOS, Windows and Linux aarch64 are not built or tested in this release.

## Contents

- Two JSON Schema profiles. `canonical-v1` is the default, a frozen subset. `spec-v1` is in alpha and adds combinators, `pattern`, numeric bounds and references.
- Literal-set constraints.
- Unsupported input is rejected at compile time with a JSON Pointer; mask computation runs under hard memory budgets.
- C ABI version 1 (`include/bolorgir.h`), the Python package and the Hugging Face Transformers adapter.

## Limitations

- `spec-v1` is alpha: on some schemas a mask call ends with `RESOURCE_LIMIT` instead of a mask.
- Standalone regular expressions and arbitrary grammars are not supported.
- Tokenizers: byte-level BPE and SentencePiece with byte fallback; other decoder chains are refused.
- No vLLM or SGLang integration yet.

The full list is in the README section [Schema profiles and limitations](https://github.com/wpartscom/bolorgir#schema-profiles-and-limitations). Changes in this release: [CHANGELOG.md](https://github.com/wpartscom/bolorgir/blob/main/CHANGELOG.md#010---2026-10-02).
